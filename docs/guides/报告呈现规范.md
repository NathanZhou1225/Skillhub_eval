# 评估报告呈现规范（运营解释层 v1）

> 对应工程字段：`EvaluationReport.narrative` / `disagreement_brief` / `risk_lock_provenance`

## 三层结构

| 层 | 字段 | 受众 |
|----|------|------|
| **结论卡** | `narrative.headline_zh` | 一句话终态 |
| **原因卡** | `narrative.reasons_zh`（≤3） | 中文原因 |
| **细节卡** | per-case 表、三维分、耗时 | 可折叠 |

## 能力分来源（2.6）

- `score_total_source=average_pool_mean`：仅 happy_path + edge_case 等权均值
- 红线（refusal/adversarial）**不参与**能力均分
- `REDLINE_MODEL_DISAGREEMENT`：红线模型分歧 → 强制人工，能力分仅供参考，**不得**自动 pass

## R5 vs 红线分歧

| 场景 | 综合分 | 人工 |
|------|--------|------|
| `MODEL_DISAGREEMENT_R5` | null | 必须 |
| `REDLINE_MODEL_DISAGREEMENT` 仅 | 可展示 average_pool_mean | 必须 |
