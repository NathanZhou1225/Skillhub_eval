# 5 状态前置判定规则

J1-J5 之前**必先识别个股当前所处的"市场状态"**。这是本 skill 区别于"模板化诊断工具"的核心设计 — 避免对低换手、无事件、板块横盘的"平静票"强行归因到具体驱动力，也避免对涨停异动股套用"平静评估"框架。

## 5 状态判定优先级（从高到低）

按优先级顺序判定，**任何一档命中 ≥2 条信号即定为该状态**，不要再继续往下判。

### 1. 个股异动态（最高优先级）

**特征**：单日发生强烈个股事件，必须立即归因。

**触发信号（≥2 条）**：
- 单日涨跌幅 > ±5%
- 单日换手率 > 5 日均换手率 × 2
- 突发公告（业绩超/不及预期、重大资产事项、大股东减持/增持公告、退市风险警示等）
- 大宗交易异常（单日 > 流通市值 1%）

**典型案例**：
- 三丰智能 2026-05-15 +19.94%（顶格 20CM 涨停板）— 同时满足"单日涨幅 > 5%"+"换手放大"

**分析侧重**（决定**核心维度里写什么视角**，见下文「注意力路由」）：
- J1 主驱动倾向：事件驱动 / 资金面驱动 / 概念主线驱动
- 重点回答：异动归因（为什么涨/跌）+ 持续性（今日 ≠ 趋势）+ 兑现 vs 反转判断
- 风险段重点：异动后 2-3 日分歧期（洗筹再启动 vs 情绪见顶），仅用动能/情绪表述，**禁止具体价位**

---

### 2. 板块共振态

**特征**：个股与所属板块同涨同跌强相关，alpha 微弱。

**触发信号（≥2 条）**：
- 个股与板块 20 日收益相关性 ≥ 0.6（数据未接通前用同向天数 ≥ 12/20 替代）
- 同向涨跌天数 ≥ 12/20
- 个股 20 日累计涨跌与板块偏离 < 3 个百分点

**分析侧重**：
- J1 主驱动倾向：市场风格 / 概念主线
- 重点：板块逻辑为主，个股 alpha 为辅
- 板块强弱、板块内龙头/同业表现是核心数据
- J4 跟随判定：强跟随板块

---

### 3. 活跃热点态

**特征**：持续高换手、概念榜前列、累计涨幅显著。

**触发信号（≥2 条）**：
- 20 日均换手率 > 3%
- 60 日累计涨幅 > +25%
- 60 日内至少 1 次涨停
- 在主流概念榜前列（机器人 / AI / CPO 等主线 Top 10）

**典型案例**：
- 中际旭创 2026-05-14 — 60 日大幅上行、千元股、CPO 概念榜首

**分析侧重**：
- J1-J5 标准框架找驱动 + 兑现概率
- J3 阶段判定是核心：共识形成 / 扩散 / 充分 / 衰退
- 风险段重点：估值是否已充分反映 + 主线高低切换窗口

---

### 4. 阶段切换态

**特征**：处于趋势转折点，方向尚未完全确认。

**触发信号（≥2 条）**：
- 突破或跌破中长期均线结构 + 量能突变（用 `technical_snapshot` 枚举，勿写均线具体价格）
- 形态信号（W 底 / M 头 / 三角整理突破）
- 共识扩散 → 衰退的转折信号（如龙头滞涨 + 二线补涨）

**分析侧重**：
- J1 主驱动倾向：J3 阶段为主（处于哪个转折点）
- 重点：判断"真切换"还是"假突破" — 看量价配合、后续 2-3 日动能确认
- 观察信号：仅写「动能确认锚点」「前低/前高区间」「承接强弱」等定性表述，**禁止止损位/二次确认具体价位**

---

### 5. 平静无驱动态（最低优先级 — 也是 A 股大多数股票的常态）

**特征**：低换手 + 小区间震荡 + 无重大事件。

**触发信号（≥3 条）**：
- 20 日均换手率 < 1%
- 60 日累计涨跌在 ±15% 内
- 近 90 日无重大公告 / 财报超预期或低预期
- 板块横盘
- 北向变化 < ±0.5%（数据可用时）

**典型案例**：
- 贵州茅台 2026-05-14 — 换手极低、60 日小幅下行仍在平静区间

**特殊处理（与其他状态不同）**：

平静无驱动态是 A 股**大多数蓝筹股、估值消化期个股、行业横盘期个股的常态**，不是异常。此时分析框架需切换：

- J1 单行：无明显单一驱动 + 无驱动证据（定性，不带数字）
- 完整诊断重心从"找驱动"切到"评估稳态"：核心维为【基本面】【概念 / 产业链】
- 【总结前瞻】融合段写「当前无明显趋势」，不强行写追涨风险评级
- 【技术面】默认走「极简空标签」；仅当触发「临界演化」时，允许在【技术面】写**动能定性**（仍禁止具体价位）

---

## 注意力路由规则（V5 · 与 6 维篇幅联动）

状态判定完成后，**必须先查表确定 1–2 个核心驱动维度**，再写 6 维。**6 个章节标题与物理顺序不可变**（基本面 → 技术面 → 资金面 → 消息面 → 概念 / 产业链 → 市场环境）。

### 状态 → 核心维度矩阵

| 市场状态 | 核心维度（满写三段式 + 数据竖排） | 次要维度（固定极简空标签） |
|----------|-----------------------------------|----------------------------|
| 个股异动态 | 【消息面】【资金面】 | 基本面、技术面、概念/产业链、市场环境 |
| 板块共振态 | 【概念 / 产业链】【市场环境】 | 基本面、技术面、资金面、消息面 |
| 活跃热点态 | 【消息面】【概念 / 产业链】 | 基本面、技术面、资金面、市场环境 |
| 阶段切换态 | 【资金面】【市场环境】 | 基本面、消息面、概念/产业链；技术面仅动能定性、无价位 |
| 平静无驱动态 | 【基本面】【概念 / 产业链】 | 资金面、消息面、市场环境；技术面默认空标签（临界演化除外） |

### 与分析侧重的联动（叠加生效，不互相替代）

| 机制 | 管什么 | 不管什么 |
|------|--------|----------|
| **注意力路由** | 哪 2 维**写满** vs **空标签**；数据竖排密度 | 不替代状态判定优先级 |
| **分析侧重** | 核心维**内部论述视角**（如异动态写归因+持续性；平静态写稳态+板块出清） | 不改变 6 维章节是否出现 |

**执行顺序**：
1. 按优先级判定主状态（可复合，见下节）。
2. 查表 → 标记核心维 / 次要维。
3. Step 3 只对核心维做事实抽取；次要维**禁止编造数字**。
4. J1 单行回链须指向**核心维**章节名（`详见上方【XX】【YY】` 可写在 ▎ 后同一行内）。

## 状态判定流程

```
取数完成 → 计算关键指标（含 technical_snapshot 枚举）→ 按优先级判定状态 → 查注意力矩阵 → 写 6 维（满写/空标签）→ J1-J5 单行
```

## 边界 / 模糊情况

**多状态同时命中怎么办**：按上表优先级，**取优先级最高的状态**。
- 例：今日 +19.94% 异动 + 与板块同向 → 个股异动态（异动是主因，板块共振是次因，在 J1 单行中可同时引用）

**信号不足怎么办**：如各状态均不足 2 条，**优先归入"阶段切换态"或"平静无驱动态"**，并在【总结前瞻】融合段标注"信号偏弱，归入 X 态"。

**异动方向相反怎么办**：异动既可能是大涨也可能是大跌；分析侧重一致（归因 + 持续性），但 J5 单行风险侧重点不同：
- 大涨异动：估值压力 + 情绪退潮 + 高位震荡
- 大跌异动：基本面下行 + 流动性 + 二次探底动能

## 临界状态 / 状态演化判定

A 股大量"看似平静、实则正在演化"的票需要复合状态表达。强行单选一个状态会丢失重要信号。

### 触发条件：何时使用"复合状态"表达

满足任一条件即应使用复合状态：

- 当前主状态命中 ≥ 2 条信号，但**今日新增**了一条次状态的强信号
- 中长期结构今日刚被突破或跌破（用 `breakout_60d_high` / `broke_60d_low` 等枚举，正文不写具体价格）
- "昨天判断" vs "今天判断" 出现明显的阶段深化 / 退潮信号
- 量能 / 换手 / 情绪指标处于临界值附近

### 复合状态命名规则

格式：`<主状态> → 临界（向 <次状态> 演化）` 或 `<主状态> + <次状态观察期>`

- 例 1（茅台 5/15）：`平静无驱动态 → 临界（向阶段切换态向下演化）`
  - 主状态：60 日仍在 ±15%、换手极低 → 满足平静无驱动
  - 触发临界：今日跌破前低区间并创 60 日新低动能 → 阶段切换向下的初步信号
  - 处理：核心维仍按平静态路由（基本面 + 概念）；【技术面】可写动能定性；J3 单行标演化

- 例 2（中际旭创 5/15）：`活跃热点态 + 板块共振中后段 + 高位首日调整观察期`
  - 主状态：60 日大幅上行、板块榜首 → 满足活跃热点
  - 触发临界：创新高次日高开低走 → 共识扩散末段 → 接近共识充分期
  - 处理：J3 单行写共识深化；J5 单行突出主线切换 + 估值

### 状态演化（昨天 vs 今天）— 强制输出（V5）

满足以下**任一**即视为存在演化，**禁止**只写今日静态状态：

- 主状态优先级发生变化
- 同一主状态下 J3 阶段深化/退潮
- 触发「复合状态」任一条件

**必须落点（至少两处 · V5.1 词表）**：
1. 【总结前瞻】融合段：`昨日 <短述> ➔ 今日 <短述>`，并含核心风险 **风险加剧 / 风险缓和 / 风险持平**（禁止「升级/降级」）
2. J3 单行末尾：`（共识深化|共识退潮|阶段持平 — 与昨日相比）`（禁止「升级/降级」）

**可选第三处**：【今天告诉客户什么】自然段内 1–2 句确认/证伪观察（**禁止**重复总结中的驱动归因；**禁止具体价位**）

**无演化时**：【总结前瞻】写「与昨日相比无明显档位变化」；J3 带 `（阶段持平 — 与昨日相比）`。

**数据不足时**：不得臆造昨日状态；总结**不写** ➔；J3 仍用 `（阶段持平 — 与昨日相比）`；【数据备注】写「暂无法对比昨日」。**禁止**「首次诊断无昨日对比基准」。若总结已写 ➔，数据备注**不得**写无法对比昨日。

### 复合状态在 V5 下的写法变更

- **【总结前瞻】**：不再分「状态：/驱动：/核心风险：」行；全部并入 **80–120 字融合短文**（无三档评级）。
- **J1**：单行一句；次状态新信号并入该行或 J3，**不再使用** `特例补充：` 子段。
- **【今天告诉客户什么】**：不再分「关键位置/观察信号」子标签；改为 **一段自然段**（含 1–2 个确认/证伪观察句）。

### 临界状态确认 / 证伪的下一步观察（定性示例）

任何复合状态都应在【今天告诉客户什么】自然段中给出**确认 / 证伪**观察：

- 例（向下演化）：`若后续 2–3 日快速收复前低区间且量能萎缩，则偏向假突破回归平静态；若跌破动能确认锚点且放量，则阶段切换向下确认。`
- 例（主线切换）：`若同业同步反弹且机器人板块分歧，则切换证伪；若光模块持续走弱而机器人继续走强，则切换确认。`

| 信号 | 缺口 | 替代方案 |
