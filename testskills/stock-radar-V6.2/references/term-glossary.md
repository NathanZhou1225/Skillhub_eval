# 术语翻译白名单

本文件是术语合规清单，**首次出现的专业术语必须按本表翻译或加注**。

依据：资深投顾视角审查反馈"中英混杂术语 + 内部黑话 + 学术词"是 IM 场景下投顾翻译给客户的最大障碍。

## 强制翻译表（出现即必改）

### 一、中英混杂术语（必须全中文）

| 原词 | 替换为 | 出现场景 |
|------|-------|---------|
| Dim 维度 | 直接用中文章节名（基本面 / 资金面 / 消息面 ...） | J1-J5 依据列表 |
| Dim XX | 同上，不要保留 Dim 前缀 | J1-J5 依据列表 |
| β | 对大盘的敏感度 / 弹性系数 | J4 跟随判定 |
| r（小写斜体） | 相关性 / 相关系数 | J4 跟随判定 |
| alpha | 超额收益（首次出现可补"个股相对板块的超出涨跌幅"） | J4 跟随判定 |
| price in | 已充分反映 / 已被市场消化 | 估值段、风险段 |
| capex | 资本开支 / 扩产投入（保留括号注：capex） | AI 算力 / 周期股资本开支段 |
| EV-Sales | 企业价值/营收倍数 | 估值段（一般不用，避免直接出现） |
| PB | 市净率 | 估值段，已亏损股票特别用 |
| ROE | 净资产收益率 | 基本面段 |
| YTD | 年初至今 | 涨幅描述 |
| ETF | 指数基金（首次出现补全） | 概念 / 产业链段 |

### 三、行情切语 / 技术派术语

| 原词 | 处理方式 | 备注 |
|------|---------|------|
| 20CM 涨停 | 投顾内部稿可保留；如涉及客户解释，加注"创业板 / 科创板涨跌幅上限 20%" | — |
| 10CM 涨停 | 同上，加注"主板涨跌幅上限 10%"（如必要） | — |
| 一字涨停 / 一字封板 | 投顾保留；客户解释场景加"开盘即封死涨停" | — |
| 高开低走 | 投顾保留（资深客户也能理解）；新手客户场景补"开盘价高于昨收但盘中下行" | — |
| 开板 / 封板 | 投顾保留；客户场景补"涨停打开 / 涨停封死" | — |
| 空头排列 | 趋势转弱 / 中长期压制仍有效 | 禁止写具体均线价格；客户场景必翻译 |
| 多头排列 | 趋势转强 / 中长期支撑有效 | 禁止写具体均线价格；客户场景必翻译 |
| 压力位 / 阻力位 / 支撑位 / 止损位 / 目标价 / 止盈点 | **严禁在正文出现**（标题行现价除外） | 统一改为：短期观察锚点、中长期压制、前低/前高区间、趋势转强/转弱、放量突破中长期压制 |
| 量比 | 当日成交量与近期平均成交量的比值（量比 1 = 持平） | 客户场景必翻译 |
| 换手率 | 当日成交股数占流通股的比例 | 客户场景必翻译 |
| 流动性 / 流动性溢价 | 买卖容易程度 / 大资金进出难度 | 客户场景翻译 |

### 四、内部黑话（首次出现必加注）

| 原词 | 替换为 / 加注 | 备注 |
|------|-------------|------|
| 个股异动态 | 单日异动 + 板块联动（保留状态名作为锚点，但 IM 文本中用大白话表述判定证据） | 5 状态术语 |
| 板块共振态 | 板块整体涨跌带动型，个股自身故事少 | 同上 |
| 活跃热点态 | 持续高换手 + 概念榜前列 | 同上 |
| 阶段切换态 | 处于趋势转折点，方向待确认 | 同上 |
| 平静无驱动态 | 低换手 + 小区间震荡 + 无事件 | 同上 |
| 共识刚形成 / 共识扩散 / 共识充分 / 共识衰退 | 首次出现处必带四阶段口径注脚：`四阶段口径：共识刚形成 → 共识扩散 → 共识充分 → 共识衰退` | J3 阶段判定 |
| J1 / J2 / J3 / J4 / J5 | **必须带功能名**（J1 主驱动 · 是什么在推这只票 / J2 还能涨多久 / J3 现在处于哪个阶段 / J4 是跟板块还是独立走 / J5 主要风险点） | 编号本身无意义 |

### 四-B、演化与风险词表（V5.1 · 语义隔离 · 强制）

**两套通道不得混用**；全文（含【总结前瞻】、J3、J5）**禁止**出现「升级」「降级」。

| 语义通道 | 只允许 | 禁用 |
|----------|--------|------|
| **核心风险变化**（【总结前瞻】） | 风险加剧 / 风险缓和 / 风险持平 | 风险升级、风险降级、核心风险升级 |
| **J3 阶段演化**（相对昨日） | `（共识深化 — 与昨日相比）` / `（共识退潮 — 与昨日相比）` / `（阶段持平 — 与昨日相比）` | 升级、降级、与昨天相比（须写「昨日」） |
| **J5 风险概括** | 风险加剧、估值无锚、情绪退潮等定性 | 风险升级、阶段升级 |

| 原词 | 替换为 | 备注 |
|------|--------|------|
| 升级 / 降级 | 按上表分流 | 机器味且易与多空混淆 |
| 核心风险升级 | 核心风险加剧 | 总结前瞻 |
| 首次诊断无昨日对比基准 | （删除）改用「暂无法对比昨日」或省略 | 与正文 ➔ 矛盾 |

### 五、合规相关措辞（V5 · 黑盒动能词）

| 原措辞 | 改为 | 原因 |
|--------|------|------|
| 中线持有价值 | （V5 已删除三档评级块，勿单独出现） | 暗含持有判断 |
| 评估非建议 / 三档评级块 | （V5 不使用） | IM 冗长 |
| 建议买入 / 卖出 / 加仓 / 减仓 / 持有 / 观望 / 看多 / 看空 | **严禁出现** | 合规底线 |
| 目标价 / 止盈点 / 止损点 / 压力位 / 阻力位 / 支撑位 / MA5（xx）/ 60日高点（xx元） | **严禁在正文出现**（仅标题行允许现价+涨跌幅） | V5 技术面黑盒 |
| 需表达「关键位」时 | 短期观察锚点、前低/前高区间、中长期压制、趋势转强、放量突破中长期压制、动能确认锚点 | 统一动能词，不给绝对价位 |
| 多头/空头排列 + 具体价格 | 趋势转强/转弱 + 结构是否突破压制（无数字价位） | 防数字海与点位预测 |

### 六、流动性 / 资金类术语

| 原词 | 替换为 | 出现场景 |
|------|-------|---------|
| 主力抢筹 | 大额资金集中流入 | 资金面段 |
| 主力建仓 | 大额资金试探性流入 | 资金面段 |
| 流动性博弈型 | 靠资金推动而非靠业绩支撑型 | 概念 / 同业可比段 |
| 业绩兑现型 | 靠真实订单 / 业绩数据支撑型 | 概念 / 同业可比段 |
| 业绩与股价背离 | 公司业绩不好但股价上涨（或反之） | 风险段 |
| 题材驱动 / 概念驱动 | 靠故事 / 政策预期 / 行业热度推动 | J1 主驱动 |
| 板块情绪退潮 | 资金离开该板块 / 板块热度下降 | 风险段 |
| 高低切换 / 主线切换 | 资金从涨多的板块换到涨少的板块 — 首次出现加这行注脚 | 市场环境段 |

### 七、比喻 / 切语类术语（首次出现必加白话注）

| 原词 | 首次出现处加注 | 出现场景 |
|------|--------------|---------|
| 出清探底期 | 行业整体去库存压力期 | 周期股 / 消费股下行期 |
| 主线虹吸 | 资金被市场最强主线抽离 | 反向风格股的市场环境段 |
| 价值陷阱 | 卖方研报正向预期但市场不认可 | 业绩稳定但股价持续走弱的蓝筹股 J5 风险段 |
| 温水煮 / 温水煮型阴跌 | **禁用** — 改为"温和阴跌" | — |
| 温和阴跌 | 无需加注（投顾认知度足够） | 弱势震荡描述 |
| 放量杀跌 | 大量抛盘下挫 | 急跌走势 |
| 缩量上涨 / 缩量下跌 | 量能不足的涨/跌（市场认可度低） | 弱势上涨 / 缓慢下跌 |
| 机构博弈底量 | 没有大资金抢筹也没有大资金抛售的低成交状态 | 蓝筹股低换手描述 |
| 高位首日调整 | 创新高次日的回调 | 主升龙头风险段 |
| 二次探底 | 跌破前低再次确认下行趋势 | 弱势股技术面段 |
| 假突破 / 真切换 | 假突破 = 短暂破位后回归；真切换 = 趋势真正反转 | 阶段切换态判定 |
| 风格短暂切换 / 风格修复 | 一日内 / 短期资金风格反向；后者 = 长期风格逆转 | 市场环境段 |
| 业绩兑现型 龙头 vs 流动性博弈型 小盘 | 前者 = 真实订单/业绩支撑；后者 = 靠资金推动而非业绩支撑 | 板块内同业可比 |

**规则**：以上术语首次出现时必须在括号或破折号后加白话注（如"出清探底期（行业整体去库存压力期）"），同一份诊断内重复出现无需再注。
**严禁**：用"温水煮"这类口语化比喻 — 客户场景下容易引发歧义。

- 大盘 / 个股 / 板块 / 概念
- 北向资金 / 主力资金 / 散户

- 净利润 / 营收 / 毛利率 / 净利率 / 负债率

## 使用流程

1. 生成 IM 文本时，首次出现术语**先在术语表查**
2. 表中有"替换为"列的，**强制替换**
3. 表中有"加注"列的，**首次出现处加注**，后续重复出现无需再注
4. 表中标注"投顾保留"的，可保留但要意识到客户场景需要翻译
5. **严禁出现**的词，**任何场景都不能用**

## 维护原则

- 本表是基础白名单，需根据实际投顾审查持续扩充
- 新增词条时按"原词 / 替换为 / 出现场景"格式追加，不要修改已有条目
