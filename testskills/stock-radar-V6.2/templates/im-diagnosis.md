# IM 风格诊断文本骨架模板（V5.1 · 叙事合一）

本模板是输出形态硬约束。生成最终诊断时**严格按本模板章节顺序与锚点填空**，不要自由发挥结构。

## 产品定位（V5.1）

- **IM 纯文本 = 体检摘要短信**（优先 **500–750 字**，硬上限仍 **900 字**）。
- 详尽证据、数字展开与图表留给**后续 HTML 层**（本阶段 Prompt **禁止**出现「详见附图/图表/链接」等幻觉表述）。
- **建议阅读顺序**：标题 → 【总结前瞻】→ 【今天告诉客户什么】→ **2 个核心维** → J1–J5 → 数据备注；4 个次要维可一眼滑过。

## 硬锚点（不可删改 · 下游解析）

以下必须原样出现：

- 大标题：`【总结前瞻】`、`【今天告诉客户什么】`
- 6 维独立标题（**物理顺序固定**）：`【基本面】` → `【技术面】` → `【资金面】` → `【消息面】` → `【概念 / 产业链】` → `【市场环境】`
- 每维三段标签名：`结论：` `数据：` `解读：`（标签名不可改）
- J1–J5 各一行整标头：`J1 主驱动 · 是什么在推这只票 ▎` … `J5 主要风险点 ▎`
- 章节分隔：`———`（保留）
- 文末：`数据备注：` + 免责声明全文（与 SKILL 一致）

**V5 已废弃（不得出现）**：三档评级；【总结前瞻】内「状态：/驱动：/」分行；J 内 `结论：`、`反例排除：`、`关键节奏：` 等子标签；【今天告诉客户什么】内「关键位置：/观察信号：/风险口径：」子标签；J5 七类风险逐项列表；全文「升级」「降级」（见术语表）。

## 叙事切割 · 语义禁区（强制）

| 模块 | 只允许 | 禁止 |
|------|--------|------|
| 【总结前瞻】 | 状态名（可复合）+ Who/Why 驱动 + `昨日 … ➔ 今日 …` + **风险加剧/缓和/持平** 一句 | 操作建议、开盘观察、`若…则…`、弹性窗口、与 J3 同义的长阶段论述 |
| 【今天告诉客户什么】 | 时间窗口 + **1–2 条**证伪/确认观察句（怎么办） | 重复驱动归因、公告复述、基本面/板块展开、与总结同义的 ➔ 复述 |
| 核心维「数据」 | **1–3 条** `·` 竖排事实数字 | 第 4 条及以上；技术面具体 MA 价 |
| 核心维「解读」 | **1 句**扣回「结论」 | 新催化、新风险类型、阶段四阶段长论 |
| 次要维全文 | **固定三行废话**（见下） | 任何业绩/技术/板块/估值/承接等实词；**零数字** |
| J1–J5 | 提炼上文，每行 ≤35 字 | 新实体、新事件、未在上文出现的判断 |

### 跨段去重（Step 6 硬检）

- 【总结前瞻】与【今天告诉客户什么】之间：**不得出现相同连续 4 字及以上短语**。
- 下列主题词全文（含 J 行）各最多出现 **2 次**：分歧兑现、情绪退潮、次日承接、异动公告、估值无锚、板块共振、高低切换、共识充分、流动性博弈、放量突破。
- 同一判断（如「机器人催化」）不得在总结、客户段、J1 中**三次**重复；J1 须用 `详见上方【XX】` 回链。

## 形式硬约束

- 纯文本，禁止 markdown 符号（`#`、`**`、`` ` ``、`-` 当列表符等）
- 段落用空行分隔，章节用 `【】` 标注
- J1-J5 用 `▎` 做分隔锚点（▎ 后接**单行**正文）
- 章节之间用三个全角破折号 `———`
- 不用 emoji
- **唯一允许具体价格的区域**：标题行（现价 + 涨跌幅）
- **数字控量**：核心维数据 ≤3 条 `·`；总结/客户段各 ≤**1** 个关键数字；次要维**零数字**

## 次要维度 · 固定话术（逐字照抄）

当 `state-judgment.md` 注意力矩阵标记为**次要维**时，三段式标签仍保留，**逐字**如下（禁止改写、禁止加戏）：

```
结论：非当前主导。
数据：· 无核心异动。
解读：不作交易参考。
```

**【技术面】次要维特例**：仅当「平静无驱动态 → 临界演化」且技术面非核心时，允许替换为动能定性（仍禁止具体价位、禁止数字）；其余次要维仍用固定三行。

## HTML 证据层 · html_expanded（Phase 2e · 双轨叙事）

当维度为 **次要维**（`role=secondary`）时，bundle 除 IM 固定三行外，**必填** sibling 对象 `html_expanded`：

```
html_expanded:
  conclusion: <4–120 字>
  data_bullets: [1–5 条，每条 ≤120 字]
  interpretation: <4–200 字>
```

- Step 1 已抓取的事实，未写入 IM 核心维的部分，应填入对应次要维的 `html_expanded`
- `format_im_from_bundle.py` **不读**此字段；`render_html.py` 在 Accordion 折叠区展示「证据层展开」
- `role=core` / `secondary_technical` **禁止**出现 `html_expanded`
- 技术面 `html_expanded` 同样遵守黑盒化（禁 MA 价位/支撑阻力）

## HTML 研判层 · judgments_j_expanded（Phase 2h · 双轨叙事）

`judgments_j` 仍供 IM **单行 TL;DR**（`format_im` 只读此节点）。HTML **【核心研判】** 竖排折叠区读 sibling **`judgments_j_expanded`**（schema **1.2.0+**）：

```
judgments_j_expanded:
  j1:
    headline: <4–24 字高度概括，如「概念主线 + 板块情绪驱动」>
    conclusion: <完整结论 + 详见上方【核心维】回链>
    counter_examples: [0–3 条反例排除]
  j2:
    headline: <窗口概括>
    conclusion: <一句话>
    key_rhythm: <可选，关键节奏/时间锚>
  j3:
    headline: <阶段概括>
    conclusion: <一句话>
    footnote: <可选，四阶段口径 + 与昨日对比>
  j4:
    headline: <板块关系概括>
    conclusion: <一句话>
    footnote: <可选，β/相关替代说明>
  j5:
    risks:
      - category: 估值风险 | 主线切换风险 | …（八类枚举）
        level: 高 | 中 | 低 | 未发现
        text: <一行依据>
```

- IM **禁止** `结论：` / `反例排除：` / J5 七类逐项；上述结构**仅**出现在 `judgments_j_expanded`
- Phase 4 起 HTML **无**顶栏 `.risk-banner`；风险由 J5 行 + `risk_tone` 徽章 + 展开清单承担
- 缺 `_expanded` 的旧 bundle：HTML 降级为 headline=IM 行 + 折叠内同文

## HTML 总结层 · summary_hook_display（Phase 4 · 双轨叙事）

`summary_hook` 仍供 IM **完整**融合短文（含 `核心风险加剧/缓和/持平`）。HTML **【总结前瞻】** 读 **`summary_hook_display`**（30–110 字，省略风险句）。`format_im` **不读**。缺字段时回退 `summary_hook` 全文。

## 6 维动态缩放（V5.1）

| 类型 | 篇幅 | 数据段 |
|------|------|--------|
| 核心维（1–2 个） | 每维 ≤80 字 | 1–3 条 `·` |
| 次要维（4 个） | 每维 ≤40 字（固定话术约 30 字） | 固定三行，零数字 |
| 【技术面】临界 | 动能仅 1–2 条枚举语义 | 无价位 |

## 章节字数规约

| 章节 | 目标 | 硬上限 |
|------|------|--------|
| 全文 | 500–750 字 | 900 字 |
| 【总结前瞻】 | 80–110 字 | 120 字 |
| 【今天告诉客户什么】 | 70–110 字 | 120 字 |
| 核心维 ×2 | 各 ≤80 字 | 90 字 |
| 次要维 ×4 | 固定话术 | 40 字/维 |
| J1–J5 | 合计 ≤180 字 | 200 字 |

超过上限必须砍内容：**先砍次要维（已固定）→ 再砍核心维解读 → 禁止砍硬锚点**。

## J1–J5 写作硬规约（V5.1 · TL;DR）

- J 是**结论提取器**：**禁止引入任何新信息**；禁止复述 6 维已出现的具体数字。
- J1 必须含 `详见上方【XX】`（与注意力矩阵核心维一致）。
- J3 末尾固定：`（共识深化|共识退潮|阶段持平 — 与昨日相比）` — **禁止**「升级」「降级」。
- J5 用「风险加剧」类表述，不与 J3 阶段词混写。
- 禁止 J 内出现 `结论：`、`反例排除：` 等子标签。

## 演化感（强制 · V5.1 词表）

有「昨日 → 今日」变化时：

1. 【总结前瞻】：`昨日 … ➔ 今日 …` + **风险加剧 / 风险缓和 / 风险持平**（禁止「风险升级/降级」）。
2. J3：`（共识深化|共识退潮|阶段持平 — 与昨日相比）`。

**无演化时**：总结写「与昨日相比无明显档位变化」；J3 用 `（阶段持平 — 与昨日相比）`。

**数据不足时**：不得臆造昨日；总结不写 ➔；J3 用 `（阶段持平 — 与昨日相比）`；数据备注写「暂无法对比昨日」。**禁止**「首次诊断无昨日对比基准」。

**有 ➔ 时**：数据备注**不得**同时写「暂无法对比昨日」。

## 数据容灾（与 data-sources.md 联动）

- `fund_flow_error` → 【资金面】数据可「暂缺」；数据备注声明。
- `info_error` → 【基本面】核心维不得写需 info 的 PE/市值数字；数据备注声明。
- 禁止用 WebSearch 补造已失败接口的同一类数字。
