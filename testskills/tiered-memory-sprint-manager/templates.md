# Templates

Read this file when creating new sprint or backlog files (Mode A).

## SPRINT file template

Path: `.project_memory/active/SPRINT_<feature_name>.md`

```markdown
# Sprint: [Feature Name]

**Sprint root:** [workspace root or subfolder path]
**Goal:** [One sentence outcome]
**Status:** Active

## Context

[Why this sprint exists; link to backlog item if applicable]

## Tasks

- [ ] Task 1
- [ ] Task 2
- [ ] Task 3

## Notes

[Optional: decisions made during sprint, blockers]
```
